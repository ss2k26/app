# Container platform: Traefik + Portainer + multi-database + PHP apps

One layout for a Windows/WSL dev PC and a VPS. Same compose files everywhere; only a small `.env` per stack changes.

| # | Requirement | How it is solved |
|---|---|---|
| 1 | Multiple database servers | `stacks/databases/`: **mysql56, mysql84, mariadb, postgres**. One folder each, independent start/stop, separate data dirs and host aliases. Add more by copying a folder ([docs/databases.md](docs/databases.md)). |
| 2 | Remote access through socat | Every engine has a **socat proxy**. For MySQL-family, mysqld shares socat's network namespace, so root (localhost-only) still works for remote PCs. Bind address, port and an allowed-IP range are env variables. |
| 3 | Easy SSL + hosts on Windows | mkcert CA + wildcard cert for `*.mysite.test` generated by a container; `windows/1-install-cert.bat` trusts it once. Hosts: optional **wildcard DNS** container (`2-setup-dns.bat`, nothing to edit per app) or the auto-scanning hosts script (`3-update-hosts.bat`). |
| 4 | dev + prod (domain/LE, IP:port/self-signed, or both) | Each app has **one** `compose.yml` with three routers (dev / domain / IP). Variables switch them on; unused ones stay on a never-matching host. |
| 5 | Portainer **and** CLI | Absolute `${APP_ROOT}` paths, Portainer data on a host bind mount, compose project name = stack name, and a `bin/platform` wrapper that is plain `docker compose`. See [docs/portainer.md](docs/portainer.md). |

## Layout

```text
/app  (symlink to /mnt/d/app on WSL, /home/ubuntu/app on a VPS)
├── bin/platform                   CLI wrapper (init, up, down, logs, exec, certs, new-app ...)
├── .env.example  -> .env          PLATFORM_ENV=dev|prod, PLATFORM_STACKS=..., TZ
├── images/php/                    ONE Dockerfile -> local/php:5.6 | 7.2 | 7.4 | 8.3
├── stacks/
│   ├── core/
│   │   ├── traefik/               edge router + cert generator   (networks: edge)
│   │   ├── portainer/             web UI                          (edge)
│   │   └── dns/                   dev only: wildcard *.mysite.test
│   ├── databases/
│   │   ├── mysql56/ mysql84/ mariadb/ postgres/                   (network: data)
│   └── apps/
│       ├── _shared/nginx.conf.template   one nginx config for all apps
│       ├── _templates/{laravel,php}/     source for `platform new-app`
│       ├── bengkel/  panglima-kediri/    compose.yml + .env.{dev,prod}.example
├── windows/                       cert trust, wildcard DNS, hosts fallback (.bat = double-click)
├── certs/  data/  htdocs/         generated certs, database/portainer data, source code (git-ignored)
└── docs/
```

Two Docker networks instead of one: **edge** (Traefik <-> web containers) and **data** (php containers <-> databases).
A web container is never on the database network, and databases are never reachable from Traefik.

## Quick start: dev (Windows + WSL Debian)

```bash
sudo ln -s /mnt/d/app /app && cd /app
bin/platform init dev            # networks, data dirs, .env files
bin/platform build               # PHP images (once; php56 php72 php74 php83)
bin/platform up                  # traefik, portainer, mysql56 (PLATFORM_STACKS in .env)
bin/platform up bengkel          # an app (code in htdocs/bengkel)
bin/platform exec bengkel php composer install
```

Then on Windows (double-click): `windows\1-install-cert.bat` (once), and either `2-setup-dns.bat`
(wildcard, once) or `3-update-hosts.bat` (re-run when you add an app). Open `https://bengkel.mysite.test`.
Details and troubleshooting: [docs/windows-dev.md](docs/windows-dev.md).

## Quick start: prod (VPS)

```bash
sudo ln -s /home/ubuntu/app /app && cd /app
bin/platform init prod
nano stacks/core/traefik/.env stacks/apps/bengkel/.env     # ACME email, domain, server IP, DB passwords
bin/platform build php72
bin/platform up traefik portainer mysql56 bengkel
```

Domain + Let's Encrypt, IP + custom port, or both at once: [docs/production.md](docs/production.md).

## New app

```bash
bin/platform new-app shop laravel 8.3     # or: new-app legacy php 5.6
bin/platform init && bin/platform up shop
```
It creates `stacks/apps/shop/` (+ next free IP port) and `htdocs/shop/`. In the app, use `DB_HOST=mysql56` (or `mysql84`, `mariadb`, `postgres`), port 3306 (5432 for postgres).

## Everyday commands

```bash
bin/platform list | status
bin/platform logs bengkel web
bin/platform sh bengkel                    # shell in the php container
bin/platform dc bengkel run --rm php php artisan migrate
bin/platform restart mysql56
bin/platform certs --force                 # regenerate the certificate (new names / new IP)
bin/platform down bengkel -- --volumes     # args after -- go straight to docker compose
```
`bin/platform dc <stack> ...` is `docker compose` with the right `-f`/`--env-file`; `platform config <stack>` prints the result.
